# Daily News Digest + «Призма»

Автоматический сборщик новостей и iOS-приложение поверх него.

| Компонент | Что делает |
|---|---|
| `collect_news.py` | Дважды в день собирает ~85 RSS-источников (русские в приоритете), кластеризует статьи в сюжеты с несколькими перспективами и публикует `news_data.json` / `news_compact.json` |
| `ios/` | Приложение **«Призма»** (SwiftUI, iOS 17+) — аналог Particle: лента сюжетов, взгляды разных изданий, категории, закладки, офлайн — см. [ios/README.md](ios/README.md) |
| `news_digest.py` | Утренний email-дайджест (отдельный workflow) |

## Пайплайн данных

1. Параллельный сбор RSS из ~85 источников (RU: РИА, ТАСС, РБК, Коммерсант, Ведомости, Meduza, BBC Russian, N+1, Sports.ru и др.; EN: BBC, Guardian, Bloomberg, FT и др.).
2. Определение языка по кириллице, дедупликация.
3. Кластеризация сюжетов: TF-IDF с лёгким русским стеммингом, best-match leader clustering (отдельно RU и EN).
4. Добор второго источника через DuckDuckGo для одиночных сюжетов.
5. Полные тексты статей через trafilatura, фильтры промо/пейволлов/бот-заглушек.
6. Ранжирование: охват × вес источников × свежесть, бонус русскоязычным сюжетам (квота `RU_SHARE=0.6`).

Параметры через переменные окружения: `MAX_STORIES`, `HOURS_BACK`, `RU_SHARE`, `DDG_ENABLED`, `RU_THRESHOLD`, `EN_THRESHOLD`.

## Запуск вручную

```bash
pip install -r requirements.txt
python collect_news.py
```
