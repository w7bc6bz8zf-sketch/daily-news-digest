# Призма — новости с разных сторон

iOS-приложение в духе [Particle](https://apps.apple.com/am/app/particle-personalized-news/id6683283775): каждый сюжет собирается из нескольких изданий, чтобы видеть событие с разных точек зрения. Русскоязычные источники — в приоритете.

## Как это работает

```
GitHub Actions (2 раза в день)
  └─ collect_news.py: ~85 RSS-источников → кластеризация сюжетов → news_data.json
        └─ raw.githubusercontent.com  ←  приложение «Призма» (iOS)
```

Сервер не нужен: приложение забирает готовый JSON прямо из этого репозитория.

## Сборка

1. Откройте `ios/Prizma.xcodeproj` в **Xcode 16+** (macOS).
2. В настройках таргета `Prizma` → Signing & Capabilities выберите свою команду разработчика (Team).
3. Выберите симулятор или подключённый iPhone (iOS 17+) и нажмите **Run** (⌘R).

Никаких зависимостей и пакетов — только SwiftUI из коробки.

## Возможности

- **Лента сюжетов** — русский заголовок приоритетно, картинка, число источников, свежесть.
- **Перспективы** — внутри сюжета выдержки из каждого издания со ссылками на оригиналы.
- **Категории и поиск** — Россия, Мир, Экономика, Бизнес, Технологии, Наука, Спорт, Культура.
- **Персонализация** — режим «только русскоязычные сюжеты», отключение отдельных источников.
- **Закладки** — сохранённые сюжеты доступны офлайн.
- **Офлайн-кэш** — последняя лента открывается без сети.

## Структура кода

```
ios/Prizma/
├── PrizmaApp.swift        # точка входа
├── Models.swift           # Story, Perspective, парсинг дат, категории
├── NewsService.swift      # загрузка JSON с GitHub + дисковый кэш
├── AppState.swift         # состояние: лента, фильтры, закладки, прочитанное
└── Views/
    ├── RootView.swift         # табы
    ├── FeedView.swift         # лента + чипсы категорий + поиск
    ├── StoryCard.swift        # карточка сюжета
    ├── StoryDetailView.swift  # сюжет и перспективы изданий
    ├── BookmarksView.swift    # закладки
    └── SettingsView.swift     # персонализация и настройки
```

## Публикация в App Store (кратко)

1. Нужен платный аккаунт Apple Developer ($99/год).
2. В Xcode: Product → Archive → Distribute App → App Store Connect.
3. Добавьте иконку 1024×1024 в `Assets.xcassets/AppIcon`.
4. Заполните карточку приложения в App Store Connect и отправьте на ревью.

## Смена источника данных

URL ленты меняется прямо в приложении (Настройки → Данные). По умолчанию:
`https://raw.githubusercontent.com/w7bc6bz8zf-sketch/daily-news-digest/main/news_data.json`
